# Getting started

1. Clone the repository.
2. Run `git submodule update --init --recursive`.
3. Install the dependencies listed in the platform build guide.
4. Configure with the relevant CMake preset.
5. Build with Ninja through `cmake --build`.
6. Run CTest.
7. Launch `umicom-studio-ide`.

See:

- `docs/how-to/build-windows-msys2.md`
- `docs/how-to/build-unix.md`

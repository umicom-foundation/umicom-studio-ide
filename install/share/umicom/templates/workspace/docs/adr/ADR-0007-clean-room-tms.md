# ADR-0007: Clean-room Umicom TMS and Calypso familiarity

Status: Accepted

Umicom TMS teaches general enterprise capital-markets concepts familiar to Calypso practitioners—trade lifecycle, data services, events, engines, workflow, transfers, messages, settlement, accounting, risk and batch—using original Umicom names, schemas and source. Licensed Calypso APIs and code remain external and private.

# ADR-0006: Native C23 LocalLLM direction

Status: Accepted

Umicom will develop native C23 ingestion, RAG, evaluation, inference and training modules. The LocalLLM is a core Framework service but does not replace the Data Server, Risk Server, Security Service or approval workflow. Implementation is phased; the 0.4.0 kit records the architecture but does not claim the production model trainer is complete.
